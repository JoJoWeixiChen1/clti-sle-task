# Reference materials

1. `ukb-ppp-olink-npx-qc-companion.pdf`: UK Biobank Pharma Proteomics Project companion material on NPX and quality control.
2. `ukb-olink-explore-1536-b0-b7-faq.pdf`: Olink/UK Biobank FAQ about assay measurements and data handling. It discusses an Explore 1536 release; use it as methodological background, not as a statement that this synthetic panel is an identical run or that all thresholds transfer unchanged.
3. `ukb-olink-explore-3072-protein-list.csv`: protein annotation lookup. The measurement matrix contains its own 2,923 assay names and is the source of the actual feature set.

These documents are supplied as study context; describe any choice to adapt them to these synthetic, two-site data.
